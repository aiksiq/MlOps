# Разбор намеренных дефектов

## 1. Данные попадали в git

**Симптом.** После `git add .` файлы из `data/` могли попасть в историю, а DVC remote не был настроен.

**Причина.** В `.gitignore` не было `data/`, а локальный DVC remote отсутствовал.

**Исправление.** `data/` и метрики исключены из git, а артефакты объявлены в `dvc.yaml`. Настроен локальный `local_remote` в `dvc_remote/`.

**Подтверждение.** `git ls-files data/` возвращает 0 файлов; `make check`, раздел 1, проходит.

## 2. DVC не пересчитывал зависимые стадии

**Симптом.** После смены версии DVC мог считать downstream-стадии актуальными и оставлять артефакты прошлой версии.

**Причина.** У `collect` не было параметров и входных файлов источника в DVC-графе, у `clean` не было зависимости от `data/raw.jsonl`. Поэтому изменение результата collect не инвалидировало clean.

**Исправление.** В `dvc.yaml` добавлены `collect`, `paths.raw`, исходные JSON-файлы и `data/raw.jsonl` в зависимости соответствующих стадий. Все три split-файла объявлены в `outs`.

**Подтверждение.** v1: 3000 raw и 1740 clean строк; v2: 6000 raw и 3324 clean строк. MD5 clean-файла меняется, а `dvc repro` запускает collect и clean после переключения версии.

## 3. Контаминация train/test

**Симптом.** Случайный построчный split мог отправить связанные вопросы в train и test.

**Причина.** `row_split` перемешивал отдельные строки, хотя ключом группы был `topic`.

**Исправление.** Реализован групповой split: все строки одной нормализованной темы назначаются одному из train/val/test.

**Подтверждение.** Для v1 contamination report: id overlap 0, text overlap 0, group overlap 0, near-dup pairs 0.

## 4. Near-duplicate проходили очистку

**Симптом.** Парафразы и примеры с переставленными вариантами ответа оставались после точной дедупликации.

**Причина.** В `clean.py` был TODO и пустое множество `near`.

**Исправление.** После точной дедупликации вызывается общий MinHash/LSH helper `near_duplicates` с параметрами из `params.yaml`.

**Подтверждение.** Раздел 2 `make check` удаляет тестовый near-duplicate: `dropped_near_dup = 1`. На v1 удалено 1233 near-duplicate строки.

## 5. Diversity был только предупреждением

**Симптом.** Вырожденный набор проходил пайплайн, хотя нарушал пороги разнообразия.

**Причина.** `diversity.py` печатал предупреждение и завершался успешно.

**Исправление.** При любом нарушении порогов стадия записывает метрики и завершает работу с ненулевым кодом.

**Подтверждение.** Раздел 6 `make check` отклоняет 1200 строк с одной темой и одним системным промптом, называя несколько нарушенных порогов. Нормальный v1 проходит: 1740 строк, 5 промптов, 442 группы.
