# Datasheet

## Назначение

Датасет предназначен для учебной демонстрации подготовки chat-данных для модели вопрос-ответ по контексту. Тема набора: extractive question answering по статьям Wikipedia.

## Источник и лицензия

Источник: SQuAD v1.1, train и dev JSON.

- Train: https://rajpurkar.github.io/SQuAD-explorer/dataset/train-v1.1.json
- Dev: https://rajpurkar.github.io/SQuAD-explorer/dataset/dev-v1.1.json
- Описание: https://rajpurkar.github.io/SQuAD/
- Лицензия источника: CC BY-SA 4.0.

Файлы скачиваются в `data/source/` и исключены из git. `collect` преобразует исходную схему в контракт проекта `id`, `topic`, `messages`. В отличие от простого копирования, он добавляет пять вариантов системной инструкции, нормализует контекст и вопрос, отбрасывает записи без непустого ответа и равномерно выбирает примеры по статьям, чтобы порядок исходного JSON не создавал перекос по темам.

## Версии

- v1: train, 3000 отобранных строк до очистки; 1740 строк после очистки.
- v2: train + dev, по 3000 строк из каждого источника до очистки; 3324 строки после очистки.

Данные не коммитятся в git. JSONL-артефакты находятся под управлением DVC, remote локальный: `dvc_remote/`.

## Формат

Каждая строка после `collect` имеет вид:

```json
{"id":"...","topic":"...","messages":[{"role":"system","content":"..."},{"role":"user","content":"Context: ... Question: ..."},{"role":"assistant","content":"..."}]}
```

## Ограничения

SQuAD содержит английские вопросы и ответы, поэтому этот учебный набор не покрывает русскоязычную лексику и не является медицинским или production-датасетом. Ответы часто короткие, а контекст взят из Wikipedia. Автоматическая очистка не заменяет ручную проверку фактов. Для реальной задачи нужно согласовать собственную предметную область, проверить права на источник и провести ручную оценку качества.

Порог near-dup равен 0.85 и одинаков в `clean` и contamination. Порог diversity оставлен из задания; датасет проходит его без ослабления.
